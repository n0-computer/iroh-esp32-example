DHT22 sensor (in the browser)

The native dht22-gui CLI, ported to WebAssembly. It runs the same live polling logic against the ESP32 sensor server, plots temperature and humidity over time, and lists each record as text. Connectivity is relay-only (browsers have no UDP/QUIC sockets), so it talks to the relay-capable ESP32 (PSRAM) variant.
