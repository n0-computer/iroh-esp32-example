# wasm-gui — browser GUI (Rust + WebAssembly)

A JavaScript GUI with logic compiled from Rust to WebAssembly. It spawns an
**iroh endpoint** in the browser (compiled to `wasm32-unknown-unknown`), shows its
endpoint ID, and acts as an **echo client** — the browser equivalent of the
[`client/`](../client) CLI.

It speaks the same `echo/0` protocol as the CLI client and the ESP32 servers:
connect to an endpoint ticket, open a bi stream, send a message, read the echo
back. Paste a ticket, type a message, hit **send echo**.

> Browsers can't open UDP/QUIC sockets, so this endpoint is **relay-only**. The
> ticket you paste must carry a relay URL — i.e. come from a relay-capable
> (**PSRAM**) ESP32 variant, not the bare-metal / no-SPIRAM ones.

The structure mirrors the
[`browser-echo`](https://github.com/n0-computer/iroh-examples/tree/main/browser-echo)
example from iroh-examples.

> Browsers can't open raw UDP/QUIC sockets, so the wasm iroh endpoint will reach
> peers exclusively over a relay. That means it interoperates only with the ESP32
> variants that have a relay connection — i.e. the **PSRAM** boards, not the
> bare-metal / no-SPIRAM ones.

## Layout

```
wasm-gui/
├── Cargo.toml          # cdylib crate, wasm-bindgen pinned to the installed CLI
├── src/lib.rs          # #[wasm_bindgen(start)] + exported greet()
└── public/             # static site, served as-is
    ├── index.html
    ├── main.js         # imports ./wasm/wasm_gui.js, calls into Rust
    ├── style.css
    └── wasm/           # GENERATED by `wasm-bindgen` (gitignored)
```

## Prerequisites

```sh
rustup target add wasm32-unknown-unknown
cargo install wasm-bindgen-cli   # must match the wasm-bindgen crate version (0.2.100)
```

`python3` is used for the static server (no npm dependencies required).

## Build & run

```sh
npm run build      # cargo build (wasm) + wasm-bindgen -> public/wasm/
npm run serve      # python3 http.server on :8080
```

Then open <http://localhost:8080>. Type in the box — every keystroke calls the
Rust `greet()` function across the wasm boundary and renders the result.

For faster iteration with debug symbols: `npm run build:debug`.

> Note: a static `file://` open won't work — `wasm-bindgen --target web` emits an ES
> module that must be served over HTTP.
